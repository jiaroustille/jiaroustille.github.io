## Welcome!
Hello! This is the source code for my personal website, built with Eleventy and deployed through GitHub Pages.

## Stack

- Eleventy
- Node 22.22.2
- Git and Github
- Community plugins for Eleventy
- ESlint
- VScode

## Structure

```bash
.
├── .cache/               # 11ty build cache
├── scripts/              # build & utility scripts
├── src/                  # main site source
│   ├── routes/           # pages, diary, writings, assets
│   ├── _11ty/            # filters, shortcodes, collections
│   ├── _data/            # global data
│   └── _includes/        # layouts, partials, components
└── eleventy.config.js    # Eleventy configuration
```
